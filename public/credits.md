## Poster images

`public/posters/*.webp` are **first frames extracted from the videos above**
(seeked to ~2 s, then resized and re-encoded), so reduced-motion and
slow-network visitors see the same artwork.

| File | Source | Size |
| --- | --- | --- |
| `hero.webp` + `hero.jpg` | frame from `hero` | 1600 × 900 |
| `about.webp` + `about.jpg` | frame from `about` | 1600 × 900 |
| `cta.webp` + `cta.jpg` | frame from `cta` | 1600 × 900 |
| `nft1.webp` | centre-cropped frame from `nft1` | 900 × 900 |
| `nft2.webp` | centre-cropped frame from `nft2` | 900 × 900 |
| `nft3.webp` | centre-cropped frame from `nft3` | 900 × 900 |
| `mint.webp` + `mint.jpg` | copy of the `hero` frame | 1600 × 900 |
| `roadmap.webp` + `roadmap.jpg` | copy of the `about` frame | 1600 × 900 |
| `object.webp` + `object.jpg` | procedural violet nebula (see below) | 1600 × 900 |

Regenerate with `node scripts/extract-posters.mjs` (frames),
`python scripts/make-posters.py` (hero/about/cta/nft), then
`python scripts/make-posters2.py` (mint/roadmap).

## Original, in-repo artwork

Created for this project; no third-party rights involved.

| Asset | How it is made |
| --- | --- |
| `public/texture.png` | Procedural film grain, generated by `scripts/generate_assets.py` |
| `public/og.jpg` | Procedural social card, same script |
| `public/posters/object.*` | Procedural violet nebula poster, same script |
| `public/favicon.svg`, `public/icons.svg` | Hand-written SVG |
| All doodles (stars, arrows, orbit rings, squiggles) | Hand-written inline SVG in `src/components/ui/Doodle.tsx` |
| 3D object (`#object`) | Built at runtime in three.js: icosahedron, wireframe cage, torus rings, particle field |
| Glow sprite + reflection environment | Generated on `<canvas>` at runtime (`src/three/orbisScene.ts`) — no HDRI or texture download |
| Copy, names, collection, roadmap, stats | Fictional, written for this project |

## Not used

No analytics, no tracking pixels, no ad SDKs, no icon fonts, no stock imagery,
no HDRI downloads, no third-party embeds. The only network requests at runtime
are the page's own assets, the six CloudFront videos, and the Google Fonts CSS
and font files.
